# 宠物小窝用户使用说明

适用版本：0.2.0（P1）。编写日期：2026-10-29。本文面向实际使用者，帮助你完成账号验证、宠物建档、日常记录、AI 咨询和社区交流。当前站点用于课程项目测试，请按页面提示操作；不需要安装应用或了解开发工具。

## 开始使用

在手机或电脑浏览器打开 [宠物小窝](https://pet-nest-mobile.pages.dev)。首次使用先注册并完成验证；已有账号可直接登录。请使用你有权使用的邮箱或中国大陆手机号，不要向他人索取账号、密码或验证码。

建议首次按这个顺序操作：注册并验证账号，创建一只宠物，添加喂食和体重记录，再进入 AI 助手选择该宠物提问。社区分享可以之后再开通，不影响私人档案使用。

| 想做的事               | 从哪里进入                               |
| ---------------------- | ---------------------------------------- |
| 新建或查看宠物         | 主导航“我的宠物”；手机底部“宠物”         |
| 添加六类日常记录       | 首页快速记录入口，或宠物详情中的记录入口 |
| 查看历史记录和体重变化 | 宠物详情、记录时间轴和体重成长图         |
| 向 AI 提问或查看对话   | 主导航“AI 健康助手”；手机底部“AI 助手”   |
| 发布动态和与宠友交流   | 主导航“宠友社区”；手机底部“社区”         |
| 改资料和绑定登录方式   | “个人主页”；手机底部“我的”               |
| 查看协议 版本或退出    | 个人页“设置”或“设置与帮助”               |

## 注册登录与退出

### 使用邮箱注册

1. 打开登录页，点击“注册”，选择“邮箱登录”这一标识方式。
2. 填写昵称、有效邮箱和至少 8 位密码。点击链接阅读《用户协议》《隐私政策》；阅读链接不会自动勾选同意。
3. 你确认同意后主动勾选，再点击注册按钮。
4. 到注册邮箱打开确认邮件并完成验证，返回应用，用邮箱和原密码登录。若页面提示查收邮件，仍应以实际收到邮件和完成验证为准。

若暂未收到邮件，先查看垃圾邮件、邮箱拼写和页面错误。不要连续重复注册同一地址；发送服务可能有频率限制。当前界面没有独立的密码找回入口，遇到无法自行解决的账号问题，请联系向你提供测试入口的维护者。

### 使用手机号注册

1. 点击“注册”，选择“手机号登录”，填写中国大陆 11 位手机号。页面已固定显示 +86，无需再填其他地区区号。
2. 填写昵称、至少 8 位密码，阅读两份协议并主动勾选同意后提交。
3. 在出现的“短信验证码”输入框填写本应用最新申请的 6 位数字，点击验证按钮。验证码五分钟内有效。
4. 验证完成并成功登录后进入应用。之后使用该手机号和原密码登录；日常登录不是“只输入短信验证码”。

如已收到验证码但验证框不在当前页面，在手机号注册方式下点击“已有验证码，继续验证”，填写同一目标手机号并继续确认。该入口恢复验证步骤，不会自动再发短信。需要重发时等待倒计时结束，再点击“重新发送验证码”。

### 登录与退出

在“登录”模式选择邮箱或手机号，填入对应标识和该账号密码，点击“登录小窝”。绑定两种标识后，它们均使用原密码进入同一个账号。登录过期时重新登录即可继续读取云端资料，过期本身不删除数据。

在个人页的“设置”或桌面侧栏点击“退出登录”。共用设备使用结束后应退出；请勿在公开电脑保存密码。首次打开时若仍在加载，等待状态结束，不要把空白加载过程当作资料丢失。

## 创建和管理宠物档案

1. 在“我的宠物”点击“添加宠物”或“迎接新成员”。每个账号最多 10 只。
2. 填写名称，选择物种、性别和日期类型；补充品种、出生或领养日期、档案体重、绝育状态和备注。
3. 按需选择一张 JPG、PNG 或 WebP 头像，单张不超过 5 MB，再点击“保存档案”。
4. 保存成功后进入详情页，核对显示内容。原有档案可进入编辑页修改，编辑保存前会再次确认。

| 字段       | 如何填写                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 名称与物种 | 名称用于识别宠物；物种可选猫、狗或其他                                   |
| 日期类型   | 出生日期用于估算年龄；领养日期仅表示领养事实，不当作真实生日             |
| 档案体重   | 单位 kg，可暂不填；体重随时间的变化另用“体重记录”保存                    |
| 绝育状态   | 按已知事实选择；未绝育与资料缺失含义不同                                 |
| 备注       | 写与养护相关的信息，例如已知过敏情况；不要填身份证号、家庭地址等无关资料 |

档案和私人头像默认只对你可见。新建体重记录不会自动改写“档案体重”，两处用途不同。若文字档案保存成功而头像上传失败，页面会明确提示；在原页面重试会继续处理同一档案，请先查看已有结果。

删除前请核对宠物名称和弹窗说明。删除宠物会连同关联日常记录、AI 会话及调用明细一并清理，应用没有撤销入口。已主动发布的社区动态需要单独管理，删除私人档案不会自动撤回已经分享的社区内容。

## 添加和查看日常记录

进入快速记录页，先核对所选宠物，再选择记录类型和发生时间。填写完成后提交，回到宠物详情或记录时间轴查看。记录与宠物关联，选择错误会影响之后的查看和 AI 上下文。

| 类型 | 要记录什么                                                   |
| ---- | ------------------------------------------------------------ |
| 喂食 | 粮食类型、数量及 g 或 ml 单位                                |
| 体重 | 实际称重数值，单位 kg，以及发生时间                          |
| 驱虫 | 体内、体外或内外驱虫，补充需要的备注                         |
| 洗澡 | 发生时间和可选备注                                           |
| 用药 | 你已获知或已执行的药名、剂量和备注，仅用于客观记录           |
| 异常 | 文字描述，可附最多 9 张 JPG、PNG、WebP 图片，每张不超过 5 MB |

记录按发生时间倒序展示，可按六种类型筛选，记录较多时继续加载。刷新页面后，已成功保存的记录仍会从云端读取。当前记录支持新增、查看和删除，没有直接编辑入口；确需纠正时先确认内容，再删除错误项并重新记录。

异常记录可能出现“文字已保存，图片上传未完成”的提示。此时先保留原页面并使用重试入口，或到档案查看文字记录，不要反复新增相同事件。网络未确认时不能仅凭一次错误就认定完全没有保存。

体重成长图位于宠物详情，可切换近 7 天、30 天或 365 天。至少有 3 条有效体重记录时才绘图；数据少时继续真实记录即可，不需要填假数。可展开原始数据核对。图中趋势仅反映录入的数据，不代表健康诊断。

## 使用 AI 健康助手

先在“AI 健康助手”选择宠物，再点击“开启新对话”或选择已有会话。输入你关心的养护问题，也可点击页面提供的示例问题。问题最多 2000 字，避免填写与宠物照护无关的个人敏感信息。

AI 会结合当前所选宠物档案、最近 30 天的记录摘要，以及当前会话最近最多 10 轮成功问答。记录过多时摘要有数量和长度上限，重要事实可在本次问题中补充。AI 不读取上传图片，不要把它的文字回答理解为看过照片后的判断。

提交后，问题立即出现在对话区，并显示“正在思考”。这只是等待状态，不展示模型的具体推理内容。成功后答案直接出现，正常情况下无需刷新。收到答案后即使后台历史同步暂时失败，当前已显示的回答仍会保留。

### 历史与每日次数

界面展示所选宠物最近 30 天的历史会话。电脑左侧选择会话，手机可点“查看历史对话”按钮。历史或额度暂未同步时，点击“刷新历史与额度”。“开启新对话”只是另开一组对话，不会删除旧历史；界面只显示 30 天也不代表更早的服务端记录自动删除。

每位用户每天最多受理 20 次新提问，按北京时间 00:00 重置。后端已受理但调用失败的请求也占一次。没有配置、无效参数或无权访问等未受理请求不计次，最终以页面读取的服务端用量为准。

| 页面状态或操作     | 建议处理                                         |
| ------------------ | ------------------------------------------------ |
| 正在思考           | 等待，不连续点击发送                             |
| 已知请求仍处理中   | 页面会短时自动检查历史；该检查不再次调用模型     |
| 检查或重试同一请求 | 沿用原请求，不重复扣次；优先用于核对不确定的结果 |
| 原请求已明确失败   | 可选择“编辑后重新提问”，这会作为新请求计次       |
| 回答保存失败       | 先刷新历史核对是否已有结果，再决定下一步         |
| 当天次数已用完     | 等到下一个北京时间自然日，不通过反复刷新增加额度 |

AI 用于健康养护咨询参考，不推荐具体药品品牌、药物剂量或处方，也不能完成真实诊断。遇到大量出血、抽搐、疑似误食异物等急症，应立即联系或前往线下宠物医院，不等待聊天继续。

每条 AI 回答都应包含：“以上建议仅供参考，不构成诊疗意见。如症状持续或加重，请及时联系线下宠物医院。”

## 使用宠友社区

社区内容向已登录的社区成员展示。首次互动前，先设置独立的公开社区昵称；私人资料昵称不会自动复制过去。你可以先浏览，再决定是否开通社区资料。

### 发布动态

1. 进入“宠友社区”，点击“分享日常”。
2. 填写 1 至 1000 字正文，可添加最多 3 个标签，每个最多 20 字，使用中英文逗号分隔。
3. 可选本人宠物，社区只分享该宠物名称，不公开其私人档案或健康记录。
4. 可附最多 9 张图片，每张不超过 5 MB，格式为 JPG、PNG 或 WebP。核对你有权分享图片及其中的信息。
5. 提交后等待草稿保存、图片上传和发布完成。文字与标签通过词库检查后可发布；当前没有图片画面或图片文字识别审核。

发布中断时，原页面会保留同一动态及已上传的部分，按提示重试。明确被敏感词拒绝后可修改文字；发布结果未确认时先查看“我的动态”，避免重复发布。

### 浏览和互动

在社区切换“推荐”“关注”“我的收藏”“我的动态”。可点赞或取消、收藏或取消，在详情页评论和回复。评论最多 500 字，只支持回复同帖一级评论；当前没有多层楼中楼。

点击作者进入社区主页，可关注或取消关注，并查看其动态、关注和粉丝列表。收藏和举报是私人数据。个人主页与社区主页的累计获赞只统计当前已发布动态收到的实际点赞；取消点赞、删除或下架动态后，刷新统计会更新。

### 删除与举报

本人动态和评论可按页面入口删除并确认。删除动态会连同关联评论及互动一并删除；删除一级评论会连同它的回复删除。应用没有删除恢复入口，操作前先核对内容。

发现不当动态或评论，在详情页点击对应“举报”入口，填写具体原因并提交。举报提交不代表内容已被认定违规或立即删除；管理员会复核正文与上下文。请勿重复恶意举报或把处理结果当作系统已经审核图片安全的证明。

历史“待重新提交审核”内容只能由作者主动重新检查；被管理员下架的内容不能使用该入口直接重新发布。

## 修改个人资料和绑定登录方式

在“个人主页”修改昵称、简介或头像，点击“保存个人资料”。私人资料与社区公开昵称分开管理；如需改公开昵称，到社区入口操作。

### 邮箱账号绑定手机号

1. 保持登录，在个人中心“账号绑定”填写本人中国大陆手机号。
2. 点击“发送绑定验证码”，收到后填写 6 位数字并点击“验证并绑定手机号”。
3. 确认页面显示已绑定，必要时点击“刷新绑定状态”。
4. 之后可用该手机号和原密码登录同一个账号，已有宠物、记录和 AI 历史不变。

### 手机号账号绑定邮箱

1. 在同一账号的“账号绑定”填写未被其他账号占用的本人邮箱。
2. 点击“发送邮箱确认邮件”，到邮箱打开确认链接。若原邮箱也收到确认邮件，按提示一并完成。
3. 返回个人中心，页面会尝试刷新，也可点击“刷新绑定状态”。只有显示已确认后才视为完成。
4. 之后可用邮箱和原密码登录同一账号。页面显示“待验证”时，不要当作已经绑定成功。

验证码发送失败、倒计时或服务繁忙时按页面提示稍后重试；不要把他人的邮箱或号码绑定到你的账号。当前界面没有账号合并入口，不能用绑定功能把两个已存在账号的数据合并。

## 常见问题和反馈

| 遇到的问题       | 先做什么                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| 找不到宠物或记录 | 核对当前登录标识、所选宠物、记录筛选类型，再刷新；不同账号的数据互不相通 |
| 页面提示未配置   | 联系测试维护者；普通用户不需要填写 API Key                               |
| 手机验证码无效   | 核对申请目标和最新 6 位验证码，确认五分钟有效期；更换号码后使用新验证码  |
| 上传失败         | 核对格式、单张大小和数量，检查网络；若已有部分保存，先查看结果再重试     |
| AI 一直处理中    | 查看错误提示或点击同一请求检查，不连续发送新问题                         |
| 体重图不出现     | 确认所选时间范围内至少有 3 条真实有效体重记录                            |
| 内容被词库拒绝   | 修改确实不适合的表述；疑似误拦截可向维护者说明，不尝试绕过规则           |
| 获赞数量变化     | 当前只统计已发布动态的实际点赞，取消、删除和下架都会影响总数             |

在“设置与帮助”可查看应用版本、完整用户协议和隐私政策。当前没有独立公开客服邮箱，请联系向你提供访问地址或测试邀请的项目维护者。反馈时说明页面、时间、操作步骤和错误提示；可以提供不含账号密码、验证码或隐私内容的截图。

本应用保存的是你录入的资料。请先核对关键记录再删除，不把聊天记录当作线下兽医诊疗记录或正式病历。账号注销、整库导出等没有普通用户自助页面，需要与维护者单独确认可提供的处理方式。
