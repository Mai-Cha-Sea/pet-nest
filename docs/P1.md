# P1 功能、权限与验收

2026-10-28 用户确认进入 P1。继续复用 Vue 3 / Supabase，不增加图表库或另一套后端。P2 话题聚合、搜索、百科和交易均不实现。

## 已实现的业务

- 宠物详情的体重折线图：近 7 / 30 / 365 天，至少 3 条有效记录才绘图；展开可读原始数值，不用档案体重造点。同一时间多次称重均保留。每次读取最新最多 2000 条并明确提示上限。
- `/community`：推荐、关注、我的收藏、我的动态。推荐使用发布时间加有上限的点赞/评论权重；20 条分页。排序会随互动变化，客户端对重复 ID 去重，并非个性化推荐模型。
- `/community/new`：1–1000 字、最多 9 张 JPG/PNG/WebP，每张 ≤ 5 MiB；可选本人宠物，只复制名称，经页面说明后主动分享。不会公开宠物 ID、档案、健康记录或私有头像。
- `/community/posts/:id`：全文、图片、点赞/取消、私有收藏/取消、500 字评论、一级回复、本人删除、举报。删除父评论会删除其回复；删除动态级联删除评论及互动，图片排入持久清理队列。
- `/community/people/:id`：独立社区昵称、公开动态、关注/取消、关注/粉丝列表；个人中心提供入口。开通前可浏览，互动需要主动设置社区昵称。

所有社区页面都需登录。社区昵称和已发布内容在已登录的社区成员间可见，原 `users`、`pets`、`records` 的 RLS 没有放宽。收藏和举报仅本人可读。

## 数据库与服务端

`20261028134826_p1_community.sql` 已通过 dry-run 并应用到 `pet-nest-dev`；本地/远程四份迁移历史一致。新增 8 张开启 RLS 的 public 社区表，敏感词与每日计数放在无普通用户访问权的 `community_private` schema。

普通客户端只有 SELECT，写入走有限授权的 RPC。写函数固定空 search_path，使用 `auth.uid()`，检查归属和参数；查询 RPC 使用 invoker 权限保留 RLS。`community_review` 仅授予 service_role。客户端不接触管理密钥。实现遵循 [Supabase 函数权限说明](https://supabase.com/docs/guides/database/functions)。

发帖、评论 UUID 保证相同内容重试不重复；点赞、收藏、关注使用明确的 true/false 状态，重复请求不反转。用户行锁与数据库唯一约束处理并发；每日计数原子更新：发帖 20、评论 100、互动变化 300、举报 20、昵称修改 20，按上海自然日。不设置客户端可以覆盖的额度参数。

独立私有 bucket `community-media` 限制类型和大小；上传只允许本人草稿目录，无 UPDATE 权限。作者可读本人图片，其他成员只能给已发布动态中的图片生成短期链接。[私有存储说明](https://supabase.com/docs/guides/storage/buckets/fundamentals)。更新后的 `storage-cleanup` 已部署，同时清理两个 bucket 各自的本人队列。

## 图片审核与举报的实际操作

文字在数据库过滤敏感词，昵称及宠物名称也检查。初始词库是基础演示规则，可由管理员维护，不能声称覆盖全部违法内容或所有变体。Vue 用普通文本渲染内容，不解析用户 HTML。**没有接入第三方图像识别服务。**

有图片的动态提交为 `pending`，审核前仅作者可见。管理员在 Supabase 开发项目的 Table Editor 筛选 `community_posts.status = pending`，到 Storage 的 `community-media` 核查对应图片及正文，然后在受控 SQL Editor 执行（替换为实际已核查的 ID）：

```sql
-- 只有管理员/服务端可执行，不能在浏览器放 service_role key。
select public.community_review('实际动态UUID'::uuid, true, '人工核查通过');
-- 拒绝或下架：
select public.community_review('实际动态UUID'::uuid, false, '向作者说明具体原因');
```

举报查看 `community_reports` 的 open 行；核对关联动态或评论后，动态可通过上述拒绝动作下架并解决对应举报。评论可由管理员在 SQL Editor 中按实际 ID 删除并复核关联举报；删除父评论会删除回复。允许管理员只修改已核实的内容，不给普通用户管理权限。无需为课设另建管理后台，但正式运营需要明确审核责任人和处理时效。

审核通过或拒绝会体现在“我的动态”及详情的状态中。已发出的图片签名链接仍可能在最长 5 分钟内有效，下架不等于撤销旧链接。没有做无凭据的定时清理；中途断网产生的未关联文件需周期核查。保持与 P0 相同的维护边界。
