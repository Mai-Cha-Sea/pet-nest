# 协议、获赞总数与验收反馈更新（2026-10-29）

## 本次完成

GAP-01、GAP-02 已实现并验证。注册页提供《用户协议》《隐私政策》的可点击链接，新标签页可匿名阅读全文，不丢失注册表单内容；阅读不会自动同意。注册同意项默认未勾选，邮箱、手机号注册和恢复验证码输入均有同意检查。未提供公开署名/邮箱时，按用户决定使用“宠物小窝项目维护者”，通过测试邀请人联系，不编造客服地址。

协议覆盖课设测试用途、账号、私有资料与主动社区分享、AI 参考边界、删除影响及反馈方式。隐私政策说明数据种类、用途、服务提供方、存储/保留、删除与用户选择，提供官方说明链接。AI 条款按本项目仅用于测试、维护者不进行模型训练/微调编写；实际调用仍发送必要的宠物文字上下文给 DeepSeek，上游处理按其[官方隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)及[开放平台协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html)执行，未写成无法由项目控制的绝对保证。

新注册页面提交协议版本，数据库用服务器时间留存。普通用户无法修改记录；旧账号不自动补签。保留旧客户端和管理测试接口兼容性，缺少声明时为 NULL，该声明不作为鉴权或“已经阅读”的证明。后续修改正文时应同步更新版本常量和新的迁移，不修改已执行的迁移。

个人主页新增累计获赞、关注、粉丝统计；社区主页增加获赞总数。获赞按当前已发布动态的实际点赞合计，两处使用同一个服务端结果。取消点赞或删除、下架动态后更新，不使用前端自增或硬编码数字；统计读取失败显示错误和重试，私人资料表单仍可使用。
